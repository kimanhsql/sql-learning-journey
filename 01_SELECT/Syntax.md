# Syntax

## 1. Select all columns

```sql
SELECT *
FROM table_name
```

---

## 2. Select a single column

```sql
SELECT column_name
FROM table_name
```

---

## 3. Select multiple columns

```sql
SELECT column1,
        column2
FROM table_name
```

---

## 4. Select distinct values

```sql
SELECT DISTINCT column_name
FROM table_name
```
