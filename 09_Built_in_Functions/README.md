# Built-in Functions

## Overview

A function is a built-in SQL feature that performs a specific task and returns a value.

A function always returns a value, while a stored procedure does not have to return a value.

A function can accept one or more parameters.

Functions help reduce repetitive code and make SQL queries easier to maintain.
