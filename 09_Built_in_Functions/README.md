# Built-in Functions

## Definition

A built-in function is a predefined SQL function that performs a specific task and returns a value.

SQL Server provides many built-in functions for working with numbers, strings, dates, data conversion, and aggregate calculations.

---

## Characteristics

- Is predefined by SQL Server.
- Always returns a value.
- Can accept zero, one, or multiple parameters, depending on the function.
- Can be used in `SELECT`, `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`, and other SQL statements.
- Helps simplify SQL queries by reducing repetitive expressions.

---

## Topics

- Aggregate Functions
- String Functions
- Date and Time Functions
- Mathematical Functions
- Conversion Functions

---

## When to Use

Use built-in functions whenever you need to:

- Perform calculations.
- Manipulate string values.
- Work with dates and times.
- Convert data types.
- Summarize data by using aggregate functions.

---

## Advantages

- Easy to use.
- Improves query readability.
- Reduces repetitive code.
- Optimized by SQL Server.
- Covers many common database operations.

---

## Disadvantages

- Limited to predefined functionality.
- Some functions may reduce query performance when applied to indexed columns.
- Different database systems may support different built-in functions.
