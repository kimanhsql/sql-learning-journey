# Books

This folder contains books that support my SQL learning journey.

These books provide detailed explanations, practical examples, database design principles, and real-world SQL techniques that complement the topics in this repository.

---

## SQL Queries for Mere Mortals

Author: John L. Viescas, Michael J. Hernandez

This book focuses on writing SQL queries step by step. It explains the fundamentals of the SELECT statement, filtering, sorting, grouping, joins, subqueries, set operations, views, and data modification queries. It also introduces relational database concepts and demonstrates SQL using practical business examples.
