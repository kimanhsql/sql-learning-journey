# Mistakes

## 1. Missing Commas

Forgetting commas between columns or values causes syntax errors.

---

## 2. Forgetting GO

Some SQL scripts require `GO` to separate execution batches in SQL Server.

---

## 3. Forgetting PRIMARY KEY

Every table should have a primary key whenever possible.

---

## 4. Using VARCHAR instead of NVARCHAR

Use `NVARCHAR` when storing Unicode text such as Vietnamese.
