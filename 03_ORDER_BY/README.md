# ORDER BY Clause

## Definition

The `ORDER BY` clause is used to sort the result set of a query in ascending or descending order.

Sorting data improves readability and makes it easier to analyze, compare, and present information.

Without the `ORDER BY` clause, SQL Server does not guarantee the order of the returned rows.

---

## Characteristics

- Sorts data in ascending (`ASC`) or descending (`DESC`) order.
- Can sort by one or multiple columns.
- Can sort by column names, aliases, or column positions.
- Is usually the last clause in a `SELECT` statement.
- Can be combined with clauses such as `WHERE`, `GROUP BY`, `HAVING`, and `DISTINCT`.

## When to Use

Use the `ORDER BY` clause whenever you need to:

- Sort query results alphabetically or numerically.
- Display records from the highest to the lowest value, or vice versa.
- Organize data using multiple sorting conditions.
- Improve the readability of reports and query results.
