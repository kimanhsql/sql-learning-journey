# Syntax

## Create a View

```sql
CREATE VIEW view_name
AS
SELECT column1, column2, ...
FROM table_name
WHERE condition
```

---

## Query a View

```sql
SELECT *
FROM view_name
```

---

## Update a View

```sql
UPDATE view_name
SET column_name = value
WHERE condition
```

---

## Alter a View

```sql
ALTER VIEW view_name
AS
SELECT column1, column2, ...
FROM table_name
WHERE condition
```

---

## Drop a View

```sql
DROP VIEW view_name
```
