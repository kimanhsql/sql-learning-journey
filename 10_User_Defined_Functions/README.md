# User-Defined Functions

## Overview

A user-defined function is a function created in SQL Server by the user.

Built-in functions are provided by SQL Server, while user-defined functions are created by the user.

A UDF returns a value.

A UDF can accept parameters.

Instead of writing the same logic many times, a UDF allows us to reuse it whenever needed. They help reduce repetitive code and save time.

A UDF can contain a SELECT statement and may use WHERE and JOIN inside its body.
